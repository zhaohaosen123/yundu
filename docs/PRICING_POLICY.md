# 定价策略（可配置）

## 原则

1. 公开价格不低于对应供应商官方公开价，默认采用“官方价 × 成本系数 + 平台服务费”的透明公式。
2. 价格按输入/输出 token、缓存 token、图片张数、音频时长等计量单位分别配置；不要用一个模糊倍率覆盖所有模型。
3. 价格目录显示平台单价、计量单位和更新时间；用户看到的是统一模型别名，不显示资源池、供应商 key 或真实部署信息。
4. 促销只能通过赠送额度、阶梯折扣或月度套餐表达，不能把官方价伪装成“原价”或制造虚假节省。

## 计算模型

```text
平台单价 = max(官方参考价 × 成本系数, 官方参考价) + 平台服务费
用户扣费 = ceil(输入量 × 输入单价 + 输出量 × 输出单价 + 其他计量 × 其他单价)
```

`成本系数`、`平台服务费`、币种、税率、最小扣费单位、阶梯规则和有效期全部配置化，并在管理后台记录版本。价格变更不得追溯影响已完成请求；预扣费与结算必须幂等且不能产生负扣费。

## 面向用户的表达

可使用“统一接入、单 Key、多模型、用量明细、失败自动切换、按量计费”等真实价值点。宣传文案不得声称低于官方、无限量、100% 可用或隐藏任何附加费用。
