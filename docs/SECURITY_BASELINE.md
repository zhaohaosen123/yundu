# 安全基线

- 生产必须启用 HTTPS、Secure/HttpOnly/SameSite Cookie、精确 Origin 白名单和可信代理列表。
- 所有 API 请求执行认证、授权、配额、模型白名单和请求体大小校验；网关拒绝任意 URL 出站，防止 SSRF。
- 用户 API Key 只存不可逆哈希，展示和日志均脱敏；上游凭据按资源池隔离并支持轮换。
- 管理员启用 MFA，登录失败限速并记录不含凭据的审计事件；敏感设置修改需要重新认证。
- 错误响应使用统一公共错误码和请求 ID，禁止返回上游主机、模型真实名、栈信息、密钥或完整请求内容。
- Redis、数据库、对象存储和支付回调使用独立凭据；默认密码只允许本机开发示例，部署检查必须阻止其进入生产。
- 日志采用最小化原则：记录 request_id、用户/租户 ID、模型别名、池标识、耗时、状态和计费结果，不记录 Authorization、prompt、response 或支付密钥。
- 依赖锁定版本并定期扫描；发布前执行备份恢复、密钥轮换、限流、越权、重放、回调伪造和资源耗尽测试。
